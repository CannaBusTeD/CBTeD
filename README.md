# CBTeD

CBTeD is a creative production assistant intended to support writing, image generation, and image-to-video animation through a shared, source-first workflow.

## Project status

Initial repository established. No plugin is published yet.

## Planned components

- **CBTeD Core**: universal workflow and project continuity rules.
- **Writing Studio**: lyrics, poetry, stories, scripts, and treatments.
- **Visual Studio**: reference-led, sequential image production.
- **Animation Studio**: approved image-to-video shot planning and generation with supported tools.

## Development principles

The original Master Workflow Rules document is authoritative. Do not silently rewrite, compress, or substitute its requirements. Specialist instructions supplement rather than override it. Each module must be tested before publication.
